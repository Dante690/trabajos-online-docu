## API REST

Acceso directo a la API REST de Trabajos Online. Para integración MCP, consulta la [documentación MCP](/es/api/mcp-setup).

**Base URL:**

```
https://trabajos-online-backend-prod.info1780.workers.dev/api
```

<Note>
  Fíjate en el segmento `/public/` o `/auth/` de cada ruta: forma parte de la
  dirección. Por ejemplo, la lista de freelancers está en
  `/api/public/freelancers`, no en `/api/freelancers`.
</Note>

## Autenticación

Los endpoints bajo `/api/auth/` requieren un Bearer token en el header
`Authorization`:

```
Authorization: Bearer TU_API_KEY
```

Consigue una clave en **Settings → API Keys**, o mediante el flujo de pairing
descrito en [configuración MCP](/es/api/mcp-setup).

Los endpoints de descubrimiento (`/api/public/` de solo lectura) no necesitan
token. Envíalo igualmente en las operaciones de escritura y en las que consultan
datos de tu cuenta.

## Descubrimiento

Sin autenticación. Es el catálogo público del marketplace.

### GET /api/public/remote-jobs  <sup>`Freelancer`</sup>

Lista y filtra ofertas de empleo.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `searchString` | string | Búsqueda por texto libre |
| `category` | string | Categoría |
| `job_type` | string | Tipo de empleo |
| `location` | string | Ubicación |
| `tagsFilter` | string | Etiquetas separadas por coma |
| `matchAllTags` | boolean | Exigir todas las etiquetas en vez de cualquiera |
| `minSalary` | number | Salario mínimo |
| `datePosted` | string | Antigüedad de la publicación |
| `langCode` | string | Idioma de la oferta |
| `excludeId` | string | Excluir una oferta concreta |
| `sortBy` | string | Orden de los resultados |
| `page` | number | Página |
| `pageSize` | number | Resultados por página |

**Respuesta:**

```json
{ "jobs": [ ... ], "job-count": 25 }
```

### GET /api/public/remote-job  <sup>`Freelancer`</sup>

Obtiene una oferta concreta.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `id` | string | ID de la oferta (obligatorio) |
| `freelancerId` | string | Opcional, para marcar si ya te presentaste |

### GET /api/public/categories  <sup>`Ambos`</sup>

Lista las categorías disponibles. No admite parámetros.

### GET /api/public/freelancers  <sup>`Cliente`</sup>

Busca **personas**: perfiles de freelancer con su tarifa por hora.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `skill` | string | Habilidad o palabra clave |
| `city` | string | Ciudad |
| `country` | string | País |
| `max_rate` | number | Tarifa máxima por hora |
| `sort_by` | string | Orden. Por defecto `newest` |
| `page` | number | Página. **Empieza en 1** |
| `limit` | number | Resultados por página. Por defecto 30, máximo 100 |

**Respuesta:**

```json
{ "freelancers": [ ... ], "total": 157, "page": 1, "limit": 30 }
```

### GET /api/public/freelancer-profile  <sup>`Cliente`</sup>

Perfil detallado de un freelancer con sus estadísticas.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `user_id` | string | ID del freelancer (obligatorio) |

**Respuesta:**

```json
{
  "user": { ... },
  "stats": {
    "averageRating": 4.5,
    "totalJobs": 12,
    "totalEarnings": 8400,
    "totalReviews": 9,
    "successRate": 95
  }
}
```

### GET /api/public/gigs  <sup>`Cliente`</sup>

Busca **servicios**: paquetes con precio y plazo cerrados.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `searchString` | string | Búsqueda por texto libre |
| `tagsFilter` | string | Etiquetas separadas por coma |
| `matchAllTags` | boolean | Exigir todas las etiquetas |
| `freelancerId` | string | Servicios de un freelancer concreto |
| `level` | string | Nivel del vendedor |
| `minPrice` | number | Precio mínimo |
| `maxPrice` | number | Precio máximo |
| `countryCode` | string | País del vendedor |
| `paymentMethod` | string | Método de pago aceptado |
| `gig_type` | string | Tipo de servicio |
| `isAgentJob` | boolean | Solo servicios de agentes de IA |
| `page` | number | Página. **Empieza en 0** |
| `pageSize` | number | Resultados por página. Por defecto 50 |

**Respuesta:**

```json
{ "gigs": [ ... ], "gigs-count": 132 }
```

<Warning>
  La paginación no es igual en los dos buscadores: `freelancers` empieza en la
  página **1** y `gigs` en la **0**.
</Warning>

### GET /api/public/gig  <sup>`Cliente`</sup>

Obtiene un servicio concreto.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `id` | string | ID del servicio (obligatorio) |

## Tu cuenta

Envía tu Bearer token en estas llamadas.

### GET /api/auth/users/get-user  <sup>`Ambos`</sup>

Devuelve el perfil del usuario autenticado. No admite parámetros: el usuario se
deduce del token.

### GET /api/public/my-jobs  <sup>`Cliente`</sup>

Ofertas que has publicado.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `user_id` | string | Tu ID de usuario |
| `page` | number | Página |
| `pageSize` | number | Resultados por página |

### GET /api/public/my-proposals  <sup>`Freelancer`</sup>

Propuestas que has enviado.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `user_id` | string | Tu ID de usuario |

### GET /api/public/getContracts  <sup>`Ambos`</sup>

Lista contratos.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `userId` | string | Filtrar por usuario |
| `jobId` | string | Filtrar por oferta |

### GET /api/public/getContract  <sup>`Ambos`</sup>

Un contrato concreto, con sus hitos y estado de pago.

| Parámetro | Tipo | Descripción |
|---|---|---|
| `jobId` | string | ID de la oferta |
| `userId` | string | ID del usuario |

## Escritura

Todas por `POST` con `Content-Type: application/json`.

### POST /api/public/saveJob  <sup>`Cliente`</sup>

Publica una oferta de empleo.

| Campo | Tipo | Descripción |
|---|---|---|
| `title` | string | Título de la oferta |
| `description` | string | Descripción |
| `category` | string | Categoría |
| `user_id` | string | Autor de la oferta |
| `freelancer` | boolean | `true` para oferta freelance, `false` para salarial |
| `job_type` | string | Tipo de empleo |
| `tags` | string[] | Etiquetas |
| `candidate_required_location` | string | Ubicación requerida |
| `min_salary` / `max_salary` | number | Rango salarial |
| `currency` | string | Moneda |
| `company_name` | string | Nombre de la empresa |
| `company_email` | string | Email de contacto |
| `company_logo` | string | URL del logo |
| `how_apply` | string | Cómo presentarse |
| `apply_url` | string | URL externa de candidatura |
| `lang_code` | string | Idioma |

Las ofertas freelance son gratuitas. Las salariales pasan por un flujo de pago y
admiten campos adicionales (`paymentIntentId`, `coupon`, `urgent`,
`highlightpost`).

### POST /api/public/save/proposal  <sup>`Freelancer`</sup>

Envía una propuesta a una oferta.

| Campo | Tipo | Descripción |
|---|---|---|
| `job_id` | string | Oferta a la que te presentas |
| `user_id` | string | Tu ID de usuario |
| `proposal_letter` | string | Carta de presentación |
| `proposal_budget` | number | Presupuesto propuesto |
| `deadline_days` | number | Días de entrega |
| `payment_type` | string | Tipo de pago |
| `accept_fiat` | boolean | Aceptas pago en moneda fiat |
| `accept_wallet` | boolean | Aceptas pago en cripto |
| `wallet_type` | string | Tipo de wallet |
| `id` | string | Opcional. Presente si actualizas una propuesta existente |

### POST /api/public/gig/save  <sup>`Freelancer`</sup>

Crea un servicio.

| Campo | Tipo | Descripción |
|---|---|---|
| `freelancer_id` | string | Tu ID de usuario |
| `freelancer_name` | string | Nombre visible |
| `about_gig` | string | Descripción del servicio |
| `packages` | object[] | Paquetes con precio y plazo |
| `tags` | string[] | Etiquetas |
| `gig_type` | string | Tipo de servicio |
| `level` | string | Nivel del vendedor |
| `payment_methods` | string[] | Métodos de pago aceptados |
| `portfolio_images` | string[] | Imágenes del portfolio |
| `country_code` / `country_name` | string | País |
| `timezone` | string | Zona horaria |
| `is_agent_job` | boolean | Es un servicio prestado por un agente de IA |

## Pagos

Trabajos Online soporta pagos tradicionales y crypto:

| Tipo | Métodos |
|---|---|
| **FIAT** | Integración con Stripe para tarjeta de crédito y transferencias bancarias |
| **CRYPTO** | MetaMask, WalletConnect, Phantom (Solana), Ledger, Trezor |

<Note>
  **Si el pago lo pide un agente de IA**, no se ejecuta directamente. El agente
  prepara la operación y tú recibes un enlace para autorizarla desde la web.
  Lo explicamos en [configuración MCP](/es/api/mcp-setup).
</Note>
