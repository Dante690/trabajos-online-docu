# Announcements

We are excited to announce two significant updates in our ecosystem:

## 📕 Version 1.0 of the Documentation in Spanish, English, and German

Aiming to make our portal more accessible to the community, we have completed version 1.0 of our documentation in Spanish. This release marks a significant step towards our commitment to inclusion and accessibility.

The Spanish documentation covers all the essential aspects of our platform, including quick start guides, detailed tutorials, and API references. We hope this documentation will be a valuable resource for developers, end-users, and companies.

## 🌐 New Frontend v1.2

In parallel, we are launching version 1.2 of our frontend. This new version brings significant improvements in usability, design, and performance, ensuring a smoother and more attractive user experience.
