# Zustände von Smart Contracts

**Smart Contracts** können je nach den aktuellen Bedingungen und den Aktionen der beteiligten Parteien verschiedene Zustände annehmen. Im Falle von Escrow-Verträgen können sie einen der folgenden Zustände erreichen:

- **Deployed (Bereitgestellt)**: Gibt an, dass der Vertrag in der Blockchain bereitgestellt wurde und zur Ausführung bereit ist.
- **Completed (Abgeschlossen)**: Dieser Zustand wird erreicht, wenn der Vertrag erfolgreich ausgeführt wurde und alle vorher festgelegten Bedingungen erfüllt wurden.
- **Terminated (Beendet)**: Der Vertrag wurde beendet, entweder weil die Bedingungen erfüllt wurden oder aus einem anderen, von den Parteien vereinbarten Grund.
- **Disputed (Umstritten)**: Tritt auf, wenn eine der Parteien den Vertrag in Frage stellt, was einen Streitbeilegungsprozess auslöst.
